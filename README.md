# 🐑 MOKORUN LIFE

スマホ向けのかわいい3Dバーチャルペットゲーム。**現在は第1段階の試作版**です。

## 🎮 遊び方
1. [ゲームを開く](https://hachiwarele.github.io/mokorun-life/)（GitHub Pages公開後）
2. 「はじめる」を押す
3. 床をタップしてもこるんを呼ぶ。放っておいてもお散歩します。
4. 「ごはん」「おふろ」「あそぶ」で簡単なお世話を試す。
5. 「その他」で名前変更・おそうじ・詳細ステータスを確認。

## 📱 現在できること
- Three.js製の3Dお部屋とオリジナルの羊風キャラクター
- タップ移動、自動散歩、歩行アニメーション
- スマホ縦画面、タイトル画面、下部メニュー
- お世話の簡易試作、名前変更、コインと状態表示
- ブラウザのlocalStorageによる**同一端末の仮保存**

## ⚠️ 注意
- **Firebaseクラウド保存はまだ未実装**。ブラウザデータを消すと仮保存が消える場合があります。
- Three.jsを外部CDNから読み込むためインターネット接続が必要。
- 家具購入、料理、進化、ミニゲーム、季節演出などは今後追加。
- コインとお世話の数値は試作用の仮バランス。
